# Scripts 全体マップ

```
Scripts/
  Battle/       … 1試合の進行・戦闘・バトルUI  → 詳細は Battle/README.md
  Card/         … カード定義・1枚効果          → Card/README.md
  StatusEffect/ … 状態異常（公式ID付き）
  Summon/       … 召喚獣・アルティメット
  Disaster/     … 天変地異
  Network/      … オンライン同期・RemotePlayerAgent
  UI/           … バトル以外の画面
  Profile/ Settings/ Editor/ Effect/ Assets/
```

**ファイル移動時**: `.cs` と `.cs.meta` は必ずセット。GUID を変えない。
